# Política de seguretat / Security Policy

## Valencià

### Versions mantingudes

Este projecte manté únicament la versió actual disponible en la branca `main` i en la web pública.

| Versió | Suport de seguretat |
| --- | --- |
| Branca `main` i web publicada | Sí |
| Còpies o versions anteriors | No |

### Com informar d’una vulnerabilitat

Si detecteu una possible vulnerabilitat de seguretat, **no la publiqueu en un Issue obert**.

Utilitzeu el canal privat de GitHub:

[Informar privadament d’una vulnerabilitat](https://github.com/neurospeaker/calor-festes-castalla/security/advisories)

En l’informe, incloeu si és possible:

- Una descripció clara del problema.
- L’URL, l’arxiu o la part del projecte afectada.
- Els passos necessaris per a reproduir-lo.
- L’impacte potencial.
- Captures, registres o altres proves que ajuden a verificar-lo.
- Una possible solució, si en coneixeu alguna.

No inclogueu contrasenyes, claus, dades personals ni altra informació sensible.

S’intentarà confirmar la recepció de l’informe en un termini màxim de 14 dies naturals. Després de revisar-lo, s’indicarà si el problema ha sigut acceptat com a vulnerabilitat, si es necessita informació addicional o si queda fora de l’àmbit de seguretat del projecte. El termini de correcció dependrà de la gravetat i de la complexitat del problema.

### Àmbit de la política

Esta política cobrix possibles problemes de seguretat relacionats amb:

- El codi HTML, CSS o JavaScript del projecte.
- La configuració i publicació mitjançant GitHub Pages.
- L’exposició accidental de credencials, claus o informació sensible.
- La integritat o distribució dels arxius descarregables del repositori.
- Altres comportaments que puguen comprometre els visitants o el repositori.

Els errors en les dades, els càlculs, la metodologia, la interpretació científica, els textos o la visualització **no es consideren vulnerabilitats de seguretat**. Estos problemes es poden comunicar mitjançant els [Issues del projecte](https://github.com/neurospeaker/calor-festes-castalla/issues).

Els problemes que afecten exclusivament GitHub, GitHub Pages, Copernicus, Open-Meteo, AEMET, AdapteCCa o altres serveis externs s’han de comunicar també al proveïdor corresponent.

### Divulgació responsable

Agraïm que qualsevol possible vulnerabilitat es comunique de manera privada i que no es publique fins que haja pogut ser revisada. Les proves han de limitar-se al contingut públic del projecte i no han d’alterar, eliminar ni intentar obtindre dades alienes.

## English

### Supported versions

Only the current version available from the `main` branch and the public website is maintained.

| Version | Security support |
| --- | --- |
| `main` branch and published website | Yes |
| Previous copies or versions | No |

### Reporting a vulnerability

If you discover a potential security vulnerability, **please do not disclose it through a public Issue**.

Use GitHub’s private reporting channel:

[Report a vulnerability privately](https://github.com/neurospeaker/calor-festes-castalla/security/advisories)

Please include, where possible:

- A clear description of the issue.
- The affected URL, file or component.
- Steps to reproduce the issue.
- The potential impact.
- Screenshots, logs or other supporting evidence.
- A suggested remediation, if known.

Do not include passwords, credentials, personal data or other sensitive information.

Receipt of the report will normally be acknowledged within 14 calendar days. After review, you will be informed whether the issue has been accepted as a security vulnerability, whether additional information is required or whether it falls outside the security scope of the project. Remediation time will depend on the severity and complexity of the issue.

### Scope

This policy covers potential security issues involving:

- The project’s HTML, CSS or JavaScript code.
- GitHub Pages configuration and publication.
- Accidental disclosure of credentials, keys or sensitive information.
- The integrity or distribution of downloadable repository files.
- Other behaviour that could compromise visitors or the repository.

Errors involving data, calculations, methodology, scientific interpretation, wording or visualisation **are not security vulnerabilities**. These can be reported through the project’s [Issues](https://github.com/neurospeaker/calor-festes-castalla/issues).

Issues affecting GitHub, GitHub Pages, Copernicus, Open-Meteo, AEMET, AdapteCCa or other third-party services should also be reported to the relevant provider.

### Responsible disclosure

Please report potential vulnerabilities privately and avoid public disclosure until they have been reviewed. Testing must be limited to the project’s publicly available content and must not alter, delete or attempt to access data belonging to others.
