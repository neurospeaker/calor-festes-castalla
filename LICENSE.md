# Llicències i condicions de reutilització

Este repositori combina programari original, documentació original i resultats derivats de fonts de tercers. Per això, no tots els fitxers tenen la mateixa llicència.

## Programari original

Els fitxers `index.html`, `styles.css`, `app.js` i `scripts/` es publiquen sota la [llicència MIT](LICENSES/MIT.txt).

## Textos i materials originals

El README, la documentació, els textos de difusió i les visualitzacions originals es publiquen sota [Creative Commons Reconeixement 4.0 Internacional (CC BY 4.0)](https://creativecommons.org/licenses/by/4.0/deed.ca).

L’atribució recomanada és:

> Díaz Mataix, L. (2026). *La calor de les Festes de Castalla: comparació climàtica de dos calendaris festius, 1950–2100*.

## Dades i resultats derivats

`data.json` i els llibres de `descarregues/` incorporen o deriven de dades de tercers. No queden relicenciats per este document: conserven les condicions d’ús, atribució i redistribució dels proveïdors indicats en el README i en cada llibre. Abans de redistribuir-los o crear obres derivades, comprova les condicions vigents de cada font.

Les marques, noms i materials aliens al projecte continuen sent propietat dels seus titulars. Este document no concedix drets sobre ells.
